# Bundled music

Audio files placed here (`.mp3 .wav .m4a .aac .ogg .flac`) ship inside the
installer and appear in **Settings → Background music → Track**.

**Only add tracks you are allowed to redistribute** — CC0 / public-domain or
royalty-free music whose licence permits bundling in software. Whatever goes in
this folder becomes part of every public release. Record each track's source and
licence in `THIRD-PARTY-LICENSES.md`.

Users' own tracks don't belong here: they go in `Documents\AI Video Studio\Music`
(Settings → Open folder), or any file via Browse.
