# Sound effects for promo videos (CC0, public domain)

- `card-slide-1.ogg`, `click_003.ogg`, `impactSoft_medium_001.ogg`, `impactBell_heavy_000.ogg`:
  from the Kenney sound packs (Casino Audio, Interface Sounds, Impact Sounds) by Kenney,
  https://kenney.nl, CC0 1.0.
- `keypress-001.wav` to `keypress-006.wav`: "Keyboard Soundpack #1" by unicae_games,
  https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes, CC0.

Chosen with /brag's sound analysis (low or medium high-frequency risk, so they stay soft).
