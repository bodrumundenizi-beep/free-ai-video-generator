# Fonts for promo videos

Copies of the landing page's fonts (docs/fonts), Latin subset, from Google Fonts (October 2026):

- `bricolage.woff2`: Bricolage Grotesque (variable, weights 200-800), by Mathieu Triay.
- `atkinson-400.woff2`, `atkinson-700.woff2`: Atkinson Hyperlegible, by the Braille Institute of America.

Both are under the SIL Open Font License 1.1: https://openfontlicense.org
